# Surgery Scheduler 🏥

**Surgery Scheduler** is an interactive calendar designed to optimize the operations of surgical departments. The application allows surgeons to efficiently plan surgical interventions, avoid schedule conflicts, and coordinate with colleagues in real-time.

🔗 **[View Live Demo](https://OlehKuts.github.io./upgraded_calendar)**

## 🌟 Key Features

- **Surgery Planning:** Ability to add new entries for a specific date and time.
- **Schedule Visualization:** Two calendars (current and next month) for a quick overview of the department's workload.
- **Data Management:** Delete outdated records and edit the list of practicing physicians.
- **Patient Archive:** Access to data of patients whose surgeries have already passed but whose information is still stored in the system.
- **Local Storage:** All data (patients, doctors, schedule) is securely stored in `LocalStorage`.

## 🛠 Tech Stack

- **Frontend:** React (Functional components, custom hooks).
- **Styling:** Bootstrap / React-bootstrap.
- **Utilities:** uuid (for unique ID generation).
- **Data Storage:** Local Storage API.
- **Deployment:** GitHub Pages.

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project folder:
   ```bash
   cd upgraded_calendar
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the application in development mode:
   ```bash
   npm start
   ```
